# 中文编辑指南

用本指南检查 agent 自己准备发送的中文回复，不默认编辑用户提供的文字。遵守用户的语言、地区用词、标点和语气偏好，以及更高优先级的指令。下文的“原文”或“编辑”指对自己草稿的局部检查和修改；只有用户明确要求修改其文字时，才适用于用户原文。

## 证据范围与使用原则

这些模式用于检查 agent 的回复是否清楚、准确、自然，不用于判断作者身份。结合具体语境和例外判断：

- 把其明确的语言特征当作**优先检查的触发线索**，而非对某段文字或作者的鉴定。
- 只有触发条件和例外都吻合时才做对应编辑；频率比、词表命中或“看着像 AI”都不能单独证明应改。
- 不把这项中文研究的数字外推到英文、繁体中文的所有语域、所有模型或所有写作者。
- 每个候选项都要结合段落功能和作者语气判断。无法确定时保留原文。

原研究与规则见 [Lieflat Less AI Tone](https://github.com/larashero3-dotcom/lieflat-less-ai-tone)；本指南改写其有用思路，并补入 Patina 的中文模式分类、声音指导，以及 Shuorenhua 的范围与保真边界。这里的例句为说明而写，不是原语料或统计证据。

## A. Lieflat 的中文测量候选信号

以下十一个项目是优先检查项。改写时不要超出触发条件，也不要为了“命中”而改动原本自然、必要或有意的表达。

### 1. 虚立误解再翻案

**检查：** “不是……而是……”“并非……而是……”“不在于……而在于……”“与其说……不如说……”“你以为……其实……”等结构，是否先安放读者没有表达过的误解，再戏剧化地推翻它。重点在修辞动作，不在某个固定词。

**编辑：** 若前半确实是空设的对手观点，直接写出有材料支持的判断。保留原有对比所承载的实质差别。

**保留：** 真实的纠错、材料支撑的对照、法律或技术定义、作者真实经历中的认识变化。不要把“可能 A，也可能 B”改成只剩 B。

### 2. 句内密集顿号列举

**检查：** 一个分句里用多个顿号串起三项或更多并列成分，整句像把清单塞进正文。

**编辑：** 先判断哪些项目真正重复。只有同义重复才可合并；不同事实应保留，可调整句法、拆分成句，或按用户授权改为列表。不要用一个笼统概括词替换多个不同项目。

**保留：** 法规条目、配置项、财务科目、完整分类、确需逐项列出的资料以及 Markdown 列表。句内排比本身不是问题。

### 3. 相邻句的同一骨架

**检查：** 连续句子反复使用相同语序、相近长度和逗号位置，例如每句都是“对象＋动作，补充说明”。检查重复的是句法模板，而不只是句子差不多长。

**编辑：** 只重排或合并确有重复感的句子，保留事件先后、主语、事实和关系。必要时改变一句的结构即可。

**保留：** 步骤、平行条款、比较维度、诗性排比、对话、引文及有意重复。不要为制造“参差感”随机拆句或改变段落长度。

### 4. 揭晓式或插入式破折号

**检查：** 破折号是否反复用来制造普通判断的“揭晓”，或插入删掉也不损失信息的补充。

**编辑：** 对确属空转的部分，改为直接陈述或用适合原句的标点。不要丢掉破折号间的重要限定。

**保留：** 解释、转折、停顿、对话、省略或作者惯用的破折号。研究显示不同模型的破折号用量差距很大；单个破折号没有诊断意义。

### 5. 提示式冒号和空转列表引子

**检查：** “核心是：”“一句话总结：”“原因如下：”等提示语是否只重复后面的内容；或者一整句只宣布下面有列表，删除后上下文和列表仍完整。

**编辑：** 无独立信息的提示语可删除；若前半句在承接上文或表达结论，就保留文字，必要时只调整标点。

**保留：** 标题、列表项、引语、代码、字段名、人物原话、定义或解释性冒号，以及提示语本身承载的主张。不要删掉列表内容。

### 6. 连续编号式小标题

**检查：** 三个或更多同级标题是否连续以“一、二、三”“第一、第二、第三”等开头，而编号只是模板装饰。

**编辑：** 如果确属装饰且不影响引用，去掉编号，保留标题文字、顺序和层级。

**保留：** 法规和章节编号、时间或步骤顺序、正文中的“首先/其次”、有交叉引用的编号，以及 Markdown 有序列表。正文序数词不等于序数词小标题。

### 7. 把工具写成理想化职业人格

**检查：** 工具、系统或流程是否被写成“智慧的导师”“永不疲倦的秘书”“全能的顾问”一类理想化人物，还伴随赞美性延伸；这个比喻是否只重复正文已说过的功能。

**编辑：** 若比喻纯属包装，可直接说原文明确写出的功能。不能凭空编机制或能力。

**保留：** 能解释机制的比喻、具体人物作类比、作者有辨识度的表达、文学语境，或删掉会丢失信息的比喻。比喻本身不是问题。

### 8. 概括语盖过原文已有的细节

**检查：** “显著提升”“大幅增长”“明显改善”“大量”“众多”等概括说法，是否覆盖了本句或相邻句已有的数字、时间、对象或具体结果。

**编辑：** 把源文已经给出的具体信息接回动作或判断中，避免先概括、再重复举证。只有原文给出数字时才使用数字；没有就不补。

**保留：** 源文确实只有抽象主张、没有具体材料的情况。可在正文外提示“此处可补例证”，不能编例子，也不能因此删除原主张。

### 9. 套路开场语

**检查：** “说白了”“说穿了”“先说结论”等是否只是清嗓子，后面并没有实际的白话解释、揭示或结论。

**编辑：** 若只是空引子，可直接从内容开始。对重复出现的同类开场采用同一判断。

**保留：** 确实标示结论、语气或口语风格的表达，以及引用、对话中的原话。不要因一个短语在候选词表里就删除。

### 10. 五类有明确触发条件的翻译式结构

仅在句子因此难读、重复或显得机械时处理。现代中文吸收了许多书面句式；被动、名词化和长句本身不能作为“翻译腔”证据。

1. **过长的名词前置修饰：** 修饰语太长，读者到中心名词前需要记住多个关系或回头确认。把关系改成两个分句或后置说明；不移动事实的作用对象，也不丢限定。十五字可作初筛提醒，不能当硬阈值。
2. **“当……时”前置从句：** “当”后是完整主谓句，句首时间从句不必要地拖迟主句。若时间关系已经清楚，可改成顺接表达；若强调时间边界、条件或对比，就保留。
3. **重复话题壳：** “对于 X 来说”“就 X 而言”“关于 X”“在 X 方面”之后，句子又以 X 作主语或宾语。可把 X 放到句子自然位置；若话题壳限定了论域，则保留。
4. **机械的句首连接词：** 相邻句或段反复以“然而、此外、与此同时、总而言之、换言之”等路标开头。只在衔接关系已由上下文明示、路标重复时移入句中或删除；真正的转折、因果、补充关系必须保留。
5. **重复结论句：** “这意味着/这表明/这说明/换句话说”引出前句已经完整表达的同一结论。可并入前句或删除提示语；如果后句推出新结果、新含义或实际判断，就保留。

### 11. 非首段评论缺少回指对象

**检查：** 非首段以“值得注意的是”“更重要的是”“听起来”“看起来”“关键在于”等评论开始，却没有“这/那/此/上文”等回指，读者必须回看才能知道评论针对什么。

**编辑：** 只有指代对象在紧邻上下文中明确时，才补上回指或点明对象。若对象不清楚，不要猜；保留原句并在需要时标出衔接问题。

**保留：** 首段、对话或引文、已有回指、中文自然的零主语，以及无需回看的短段。不要把每个段首都补成“这”。

## B. Patina 与 Shuorenhua 补充的中文编辑检查

以下是可迁移的编辑判断，不是 Lieflat 研究的实测特征。它们只能在明确的局部问题出现时触发。

### 12. 空泛重要性、宣传语言和“挑战与展望”套式

检查“意义重大、影响深远、里程碑、赋能、引领、蓬勃发展、贡献突出、前景广阔、机遇与挑战并存”等词是否密集堆叠，却没有交代对象、行动、范围或依据。核对“取得成果—仍有挑战—未来可期”是否是空泛三段式。

若内容只是重复或夸大，删掉纯包装部分，保留具体成果、真实限制和作者判断。新闻稿、品牌稿、倡议、引语和正式报告可能有意采用这些表达；按体裁和用户目标处理，不把宣传腔一概改成中性文。

“在新时代背景下、随着……不断发展、值得注意的是、深入探讨、全面推动、持续赋能”等也只是检查用词，不是禁用词。只有在多次堆叠、没有具体指向或只作空开场时才考虑删改。专业术语、固定政策表达和作者有意采用的正式语体应保留。

### 13. 模糊来源与权威背书

检查“专家指出、业内人士认为、相关研究表明、数据显示、据了解”等是否没有人名、机构、时间或出处。纯编辑不能替作者查证或造来源。保留来源归属和论断，可在正文外简短标出“来源未具体说明”；不要删除“专家指出”却把其论断留成无归属事实。

若文中附近已给具体来源，保留它。常识性共识、匿名但确有含义的报道背景或被讨论的原话，也不要误删。

### 14. 填充、讨好、假细化和空洞收尾

检查纯客套开场（“非常好的问题”）、无信息的行文预告、“希望这对你有帮助”“如需了解更多请告诉我”、泛泛积极结尾，以及“严格来说/更准确地说/事情并没有这么简单”后重复前句的假细化。

如果文本并非真实对话，删除无信息的聊天残留；如果是对话或界面文案，按真实场景保留。删除假细化时先确认第二句没有真正补充限制、证据或更正。保留实际服务承诺、下一步、免责声明和礼貌边界。

### 15. 四字格、书面腔、词语替换与名词化

检查四字成语或“持续推进、全面提升、深入开展、有效赋能”等格式化词组是否叠加到妨碍清楚表达；检查同一术语是否为了“避免重复”被换成一串近义词；检查“完成了对……的……”“实现了……的提升”“进行了……的优化”是否掩盖直接动作。

必要时恢复原文已有的动词和稳定术语。不要把所有四字词改成口语词，不要删专业术语，也不要把不同概念合并成一个宽泛词。被动句、长句、名词化和标准语法在公文、学术、法律和技术中文中可能完全合适。

### 16. 泛化、虚假比较与抽象施动

检查“更进一步、进一步提升、越来越重要”等比较是否有清楚的比较对象；“从 A 到 B”是否真表示连续范围而非两个并列项；抽象对象是否被写成“赋能、引领、重塑、催化”却不说明源文已有的行动。

若关系不清，依据原文改成明确的比较或直接动词；找不到原文依据时不要补。保留有效的趋势、范围和拟人表达，不能只因“像口号”就删掉主张。

### 17. 口语词、虚词和人称

在作者原本口语化或用户要求口语化时，保留适合的“就、很、了、这事儿、其实”等语气和虚词。不要为了“有人味”自行补虚词、改成网络用语、加“我觉得”，或把客观文改成对话。

保持作者使用“您/你/我们/我/本文”的方式。不要为了去重强迫使用代词；中文重复名词有时更清楚，也可能是作者习惯。

### 18. 段落节奏、列表、标题和格式

可检查同一篇文章是否多段都重复同一种“总起—三点—总结”模板，但不要测量句长或段长、把长短改到刻意不均匀。列表、编号、加粗、表情符号和标题格式按体裁处理；先确认它们确实造成模板感或干扰，才做调整。

## 中文中不能单独作为改写理由的特征

以下特征不能因为“常见 AI 味清单”而自动更改：

- 句长、段长相近；用短句堆叠制造节奏；
- 正文中“首先、其次、最后”，或“第一”作为真实顺序；
- 句内排比、三项并列、设问、反问、问句标题；
- 比喻、独立成段的比喻、抽象名词搭配具象动词；
- 被动句、名词化、长句、规范的“的/地/得”；
- 使用完整名词而非代词、没有口语虚词；
- “然而、此外、因此”等单次且关系清楚的连接词；
- 正式词语、成语、四字格、抽象主张、客观语气。

Lieflat 的对照结果特别提醒：中文人类样本中的正文设问、比喻和句内排比并不比模型样本少；句长/段长均匀、单字虚词不足、名词重复、被动、名词化、正文“首先”、反问和句内排比也没有支持常见的机械删除建议。不要借“自然”之名把正式文本改成口语，也不要删除有意的修辞。

## 中文例子

**保留真实的对比**

原文：“这次调整没让流程更快，却让出错后更容易查到责任环节。”

保留：快慢和可追责性是不同结果，不能为了避开转折句式把它们压成一句泛泛好评。

**避免把一个解释拆成多个重复路标**

原文：“此外，材料缺少签名。因此，这意味着审批无法完成。”

可改：“材料缺少签名，审批因此无法完成。”

理由：后两句表达同一因果；若“审批无法完成”只是可能性而非事实，就必须保留原有情态。

**抽象断言不能由编辑补成事实**

原文：“专家认为这项技术会改变行业。”

安全处理：保留原句；在正文外提示“来源未具体说明”。不得改成“这项技术将改变行业”，也不得编造专家或数据。

## 中文交付前核对

- 每个实词、例子、数字和判断都能在原文找到依据吗？
- 主体、归属、否定、范围、条件、程度和不确定性都保留了吗？
- 是否误删了真实对比、列表、比喻、口语语气、引文或下一步？
- 是否把正常中文句式错判成翻译腔，或把正式文本改得过分口语？
- 触发信号是否真的符合其条件和例外，而不只是词面相似？
- 是否保留了用户的繁简体、地区词汇、标点与文档格式？
