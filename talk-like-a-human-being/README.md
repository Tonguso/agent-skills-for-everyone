# Talk Like a Human Being

A bilingual Agent Skill governing an AI agent's own everyday communication with users. It guides natural English and Chinese wording while preserving facts, uncertainty, attribution, and action status. It is not a default workflow for rewriting user-supplied text.

## Installation

Copy the whole folder into a compatible agent's skills directory. Keep the folder name and SKILL.md name field unchanged. Configure the host to apply the skill to everyday replies; copying files alone does not prove automatic activation.

## Contents

- SKILL.md: communication scope, workflow, and factual safeguards.
- references/english.md: contextual English wording checks.
- references/chinese.md: contextual Chinese wording checks.

## Author and version

Hogan Tong. Version 1.1.0.

## Influences

The wording guidance draws on editorial principles from [Patina](https://github.com/devswha/patina), [Shuorenhua](https://github.com/MrGeDiao/shuorenhua), and [Lieflat Less AI Tone](https://github.com/larashero3-dotcom/lieflat-less-ai-tone). Patterns are contextual checks, not authorship tests or statistical thresholds.
